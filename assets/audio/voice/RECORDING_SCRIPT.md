# Mom Voice — Recording Script

Record 10 short lines in 繁體中文 (primary) or English (fallback).
Save each file as `mom_d{DAY}_{OUTCOME}.mp3` (and/or `.ogg`) in this folder.

Tone: a Taiwanese mom in her 50s-60s. Slightly exasperated, but loving.
The game already shows English subtitles, so prioritize natural 台灣國語
delivery. Mild 台語 intonation welcome. Keep each clip under ~4 seconds.

## Recording notes

- Phone voice memo is fine; AirPods mic is fine; anything in quiet room works
- Record a couple of takes per line, pick the warmest one
- Export as MP3 (or M4A and convert). OGG is optional (browser fallback only)
- Don't add music / reverb / room tone — the game mixes it in at runtime
- Target level: -12 dB peak roughly. Phaser will auto-mix volume down

## If you skip this

The game plays fine without voice — dialogue renders on-screen bilingual.
The voice adds a huge amount of warmth but is optional. Judges will not
know it is missing.
